# 재난문자 → 지진 발생 장면

기존 학교 모델 파일과 이동 경로를 유지하고 `src/story/`에 스토리를 추가했습니다. 별도의 대피 선택지, 가방 보호, 대피 진행/완료 판정, 결과 화면은 없습니다. 기존 자유 이동·문·숙이기는 그대로 사용할 수 있습니다.

## 체험 순서

1. **PC 체험 시작 / VR 체험 시작**을 누르면 평온한 교실에서 시작합니다. 메뉴에 머무르는 시간은 진행 시간에 포함하지 않습니다.
2. 체험 시간 약 3초에 스마트폰이 켜지고 알림음이 울립니다. 연결된 오른손 XR 컨트롤러가 진동을 지원하면 180ms 진동합니다.
3. PC: **E**를 눌러 스마트폰을 들어 확인합니다. 화면이 올라온 후 약 .75초 읽으면 확인됩니다. 이 동작 중에는 E를 문 조작으로 동시에 전달하지 않습니다. 문 조작은 이후 정상적으로 사용할 수 있습니다.
4. VR: 오른손을 들어 화면을 헤드셋 쪽으로 향하고 바라봅니다. 거리 .22–.85m, 시선 중심 14° 이내, 화면 앞면이 머리 쪽을 향함, 눈높이 아래 .45m 이내 조건을 .75초 유지하면 확인합니다. 오른손을 찾을 때 컨트롤러 번호를 가정하지 않고 `handedness`를 사용합니다.
5. 확인한 뒤 2초에 지진이 시작됩니다. PC의 스마트폰은 자연스럽게 내려갑니다. 가구의 작은 진동, 저음·물체 떨림 소리, 약한 조명 변화, 제한된 먼지를 표현합니다. STEP 01 단독 모듈의 끝입니다. 현재 앱에서는 이 시점부터 STEP 02 판정이 이어집니다.
6. **R / 시작 위치로**: 평온한 교실로 돌아가 스토리를 다시 시작합니다. ESC 메뉴·탭 비활성화·XR 일시정지 중에는 시간과 소리를 멈춥니다.

## 구성과 성능

- `StoryTimeline.js`: 실제 활성 체험 시간에 기반한 상태 전이. 확인 전에는 지진이 시작되지 않습니다.
- `Phone.js`: 약 7.8 × 16cm의 간단한 스마트폰 3D 모델. 기존 학교와 다른 외부 모델이나 이미지 다운로드는 없습니다. 화면 캔버스는 상태가 바뀔 때만 다시 그립니다.
- `EarthquakeStory.js`: 오른손 grip에 부착, PC 들기, 머리/전화기 방향을 통한 지속 시선 판정, 가구·환경광·먼지 연출을 담당합니다.
- `StoryAudio.js`: 사용자의 시작 클릭 후 Web Audio를 활성화합니다. 알림, 낮은 진동음과 떨림 소리를 절차적으로 합성합니다. 마이크나 외부 오디오 파일을 사용하지 않습니다.
- 교실 가구를 기존 배치 최적화 과정에서 구분해 배치합니다. 원래 위치에서 X 8mm / Z 6mm 이내로 움직이며 리셋 시 정확하게 복원합니다. 같은 셀의 재질별 가구 부분은 같은 위상을 사용합니다. 건물이나 VR 카메라는 흔들지 않습니다.
- 충돌 데이터는 원래 위치를 유지합니다. 움직이는 시각 메시와의 차이는 최대 약 1cm이며 무거운 동적 물리나 매 프레임 삼각형 충돌 재생성은 사용하지 않습니다.
- 먼지는 96개 포인트와 한 draw call입니다. 조명은 기존 환경광을 약하게 변조하며 추가 실시간 그림자나 다수의 동적 조명을 만들지 않습니다.
- 지진은 실제 피해 규모나 지속시간을 계산한 물리 모델이 아닌 교육용 연출입니다.

## 검증

`npm test`로 기존 학교 경로/문/충돌 보존과 알림 3초, 확인 후 2초, 일시정지, 초기화, 스마트폰 앞·뒤/거리/시선 판정, 오른손 부착·진동 전달, 카메라 불변, 가구 복원을 검사합니다.

브라우저에서는 PC 시작, 꺼진 화면, 재난문자 수신, E로 읽기, 확인 후 지진 상태와 콘솔 오류를 확인합니다. 실제 Quest의 컨트롤러 포즈·진동·음량·프레임레이트는 기기에서 최종 확인해야 합니다. 진동이나 오디오가 지원되지 않더라도 화면과 스토리는 진행됩니다.
