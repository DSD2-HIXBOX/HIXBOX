# 학교 탐색 1.2

교실의 기존 두 문짝을 원래 출입구 평면을 따라 좌우로 이동합니다. 복제 문이나 새 레일 모델을 추가하지 않았습니다. 문이 열리면 빈 출입구로 통과할 수 있으며, 움직이는 문짝의 실제 충돌 영역과 인체를 검사해 끼임을 방지합니다. PC E / VR 트리거 조작은 같습니다.

전체 배치 검수로 확인한 서쪽 짙은 지붕 별관을 렌더링과 충돌 데이터에서 제거했습니다. L자 본관, 교실 24개 출입구, 남북 계단, 운동장과 주변 부지는 유지합니다. 제공된 원본 GLB와 이전 배포 ZIP은 보존했습니다.

본관의 형상 단순화·텍스처 축소 없이 버텍스 순서 정리와 EXT_meshopt_compression을 적용했습니다. 압축한 14,668개 버퍼를 다시 풀어 원래 바이트와 대조했습니다. 82개 이미지와 전체 재질은 그대로입니다. 충돌 파일도 gzip 해제 후 원본 바이트와 Node/실제 브라우저용 디코더 양쪽에서 대조했습니다. 웹과 앱에 디코더를 포함하므로 인터넷 없이 사용할 수 있습니다. GLB만 다른 뷰어에서 여는 경우 해당 뷰어에 EXT_meshopt_compression 지원이 필요합니다.

자동 검사 78개: 모든 문 열림·닫힘·통과·끼임, 두 계단 1–4층 왕복, PC/VR 모의 입력, 재질/이미지 보존과 압축 복원 검증을 통과했습니다. 실제 웹에서 압축 자산 로딩과 E 두 번으로 열기·닫기를 확인했습니다. Quest 실기기 및 macOS 앱 더블클릭은 이번에도 직접 검증하지 못했습니다.

크기 측정값은 release.json, 압축 검증은 compression.json에 있습니다. 원본과 백업이 있는 작업 폴더 전체 크기는 줄이지 않습니다. 실제 실행 앱과 공유 ZIP만 전달하세요.
