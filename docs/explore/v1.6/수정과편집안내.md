# 학교 탐색 1.6 · 복도 벽 연결부와 편집 프로젝트

## 틈의 원인과 수정

사진의 흰색 세로 기둥은 원래 면이 있지만, 복도를 향해야 할 앞면의 삼각형 방향이 뒤집혀 있었습니다. 단면의 안쪽 면은 약 0.5m 뒤에 그대로 있어, 단면이 비고 책상과 의자 다리가 보였습니다. 기존 벽의 삼각형 순서와 법선을 바로잡아 복도 쪽에서 정상적으로 보이게 했습니다.

같은 복도 배치의 기둥과 붙어 있는 걸레받이를 검사해 잘못 향한 삼각형 90개를 수정했습니다. 0.5m 뒤의 기존 안쪽 면이 확인된 경우만 교정했습니다. 면을 새로 덧씌우거나 문·창문 개구부에 벽을 추가하지 않았습니다. 위치, 재질, UV는 보존합니다. 상세 좌표는 corridor-wall-repair.json에 있습니다.

별도 경로의 편집 프로젝트에서도 원본 전체 재생성·자동 검사·웹 빌드를 검증했습니다.

자동 검사 88개: 기존 벽의 위치·UV·재질 및 삼각형 개수 보존, 수정한 면의 바깥 방향, 사진 위치, 문·계단·바닥·PC/VR 모의 입력을 검사했습니다. 시작점 옆 교실과 그 옆 교실의 틈이 막힌 화면을 확인했습니다. Quest 실기기와 macOS 실행 앱의 더블클릭은 직접 검증하지 못했습니다.

## 편집 가능한 ZIP

데스크톱 DSD2에 제공하는 ZIP에는 웹 소스, 모델 가공 스크립트, 검사, 외관·실내·통합 원본 GLB, 완성본의 압축 전 GLB, 현재 문/계단/충돌 데이터와 Mac 실행 앱 소스를 포함합니다.

ZIP의 `public/models/explore/render.glb`는 편집기에서 열 수 있는 **압축 전 완성본**입니다. 일반 배포 앱의 압축 GLB와 형상·재질·UV가 같고, 실행 코드도 압축 전/후 두 형식을 지원합니다. `node_modules`, 과거 백업, 빌드 중복 파일은 제외했습니다. 모델 경로를 `source-models/` 기준으로 바꿔 다른 PC에서도 원본 재생성이 가능합니다.

`README_편집안내.md`에 웹 편집, Blender 등에서 GLB 편집, 문 메타데이터 보존, 충돌 재생성, 전체 원본 재생성 및 Mac 앱 빌드 방법을 정리했습니다. 패키지에는 별도 개인 폴더 경로에 의존하는 원본 모델 로딩 코드가 없습니다.
