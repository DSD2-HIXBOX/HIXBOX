# 학교 탐색 1.3

## 참고 이미지의 벽 전체 복원

이전 1.2.1에서는 게시판 7개 부품만 복원해, 게시판 뒤 목재 마감과 왼쪽 게시물의 누락을 놓쳤습니다. 첨부 이미지와 실내 원본을 대조해 목재 마감 69개, 누락된 달력·안내문·사진, 기존 게시판과 주변 부품을 포함한 총 87개 원본 부품을 복원했습니다. 새 이미지나 임의의 평면을 만들지 않고 원본 형상·UV·재질을 사용합니다. 원래 없어진 노드도 원본에서 다시 가져옵니다. 게시판·부착물의 벽 간격은 유지하며, 목재 마감은 원래 벽 위치에 붙입니다.

## 교실 문

시작점에서 문을 바라볼 때 왼쪽 문짝은 고정, 오른쪽 문짝만 왼쪽 문짝 방향으로 평행 이동해 겹칩니다. 교실 출입문 24곳에 같은 복도 기준을 적용합니다. 반대편 복도의 문은 복도에서 바라본 좌우를 기준으로 방향을 맞췄습니다. 두 문짝을 양쪽으로 벌리거나 전체를 회전하지 않습니다. 열린 뒤 통과하는 공간은 원래 오른쪽 문짝이 있던 절반입니다. 고정 문짝은 계속 충돌을 유지합니다.

## 1층 흰색 외부 출입문

원본에서 별도 분리된 흰색 문틀·유리 부품을 분석해 9개 출입구(18개 문짝)에 여닫이 상호작용을 추가했습니다. 문은 각 바깥 경첩을 기준으로 외부 방향으로 약 90도 회전합니다. 이중 현관에서는 안쪽과 바깥쪽 문을 각각 엽니다. PC E, VR 가리키기+트리거 조작을 공통 사용합니다. 원본의 고정 옆 유리와 상부 창은 움직이지 않습니다.

문틀의 실제 높이는 약 2.696m이고 외부 발판은 약 2.396m입니다. 이전 바닥 판정은 문턱 중앙에서 외부 하부 면을 먼저 골라 발이 30cm 내려간 뒤 실내 슬래브에 걸릴 수 있었습니다. 출입문 주변에서 몸의 지지 영역을 함께 검사하고, 원본 바닥이 실제로 있는 문턱의 높이 변화만 허용합니다. 없는 바닥을 만들거나 벽 충돌을 끄지 않습니다. 동측·북측·남측 출입구에서 외부 발판으로 나갔다 돌아오는 연속 경로를 검사했습니다. 실제 바닥이 끊기는 단차·난간은 통과하지 않습니다.

## 검증

- 원본 이미지·재질 보존 및 압축 복원, 목재 마감·누락 게시물 원본 노드 복원
- 교실 왼쪽 고정/오른쪽 왼쪽 이동, 열린 절반 통과, 고정 문짝과 닫힌 문 충돌
- 흰색 문 90도 경첩 회전, 출입문 끼임 방지, 외부 발판 왕복
- 기존 양쪽 계단 1–4층 왕복, PC/VR 모의 조작 등 자동 검사 81개
- 실제 브라우저에서 벽 전체, 한쪽 미닫이, 흰색 여닫이의 화면 검수

Quest 실기기와 macOS 앱 더블클릭은 직접 검증하지 못했습니다. 사용자 원본과 이전 앱/ZIP은 백업에 보존합니다. 실행 자산은 기존 무손실 압축을 유지합니다.
