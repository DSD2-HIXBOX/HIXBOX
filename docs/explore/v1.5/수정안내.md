# 학교 탐색 1.5

3층의 수평 보행 바닥 면 11,226개 삼각형에 2층의 기존 테라조 재질과 UV 기준을 적용했습니다. 바닥 삼각형의 위치·개수·형상은 그대로입니다. 바닥 외 벽·천장과 다른 층 바닥의 재질은 유지합니다. 계단의 형상도 유지합니다.

1층 게시판의 기존 46개 부품을 제거하고 2층의 게시판·게시물·목재 배경 등 87개 부품을 정확히 3.05m 아래로 배치했습니다. 기존 게시판 위에 겹쳐 두지 않았습니다. 게시판 이미지와 재질은 2층의 기존 자산을 공유합니다.

자동 검사 86개를 통과했습니다. 3층 바닥의 모든 삼각형 보존, 2층 재질 적용, 1층 게시판과 2층 부품의 위치 차이·재질·UV 동일성, 기존 문·계단·충돌과 PC/VR 모의 이동을 검사했습니다. 실제 브라우저에서 3층 바닥과 1층 게시판을 확인했습니다. Quest 실기기와 macOS 앱 더블클릭은 직접 검증하지 못했습니다.

기존 1.4의 낮 조명과 깊이 안정화, 교실의 왼쪽 고정·오른쪽 단방향 미닫이, 흰색 외부 출입문의 여닫이를 유지합니다. 사용자 원본은 변경하지 않으며 이전 앱과 ZIP을 백업합니다.
