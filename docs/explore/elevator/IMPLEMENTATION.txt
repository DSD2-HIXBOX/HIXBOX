공통 학교 엘리베이터 — 로컬 검토용

원본: source-models/interior.glb
문짝: 4557, 4558 / 버튼: 7562~7564, 9382~9385 / 문틀: 9386
기존 GLB/충돌 바이너리는 수정하지 않음. 약 143KB JSON에 원본 메시, UV, 재질, 이미지를 추출.
원본에는 두 층의 외부 문/버튼과 문틀이 있고 객실/구동 장치가 없음.
1~4층은 같은 원본 문/버튼을 반복 배치, 3~4층은 원본 문틀도 반복 배치.
객실은 기존 출입구에 맞춰 새로 구성. 중앙 양개 미닫이와 이동 객실 문.
겹치는 기존 벽은 엘리베이터 구역에서만 셰이더로 숨김. 충돌도 같은 구역만 감싸며 원본 유지.

PC: 버튼을 보고 E. 내부 버튼에서 1~4층 선택, 열기/닫기.
문 완전 닫힘 후 이동. 문틈에 사람 있으면 다시 열림. 도착 후 문 열림.
최신 요청에 따라 기본 학교 페이지는 PC 전용. VR 입력/버튼 제거.
legacy 페이지와 다른 시나리오 소스는 유지.

시나리오 API:
window.schoolExplore.elevator.setEnabled(false) : 호출/층 이동 금지
setEnabled(true) : 허용
setPolicy(({action,floor,currentFloor})=> boolean) : 시나리오별 제한
금지해도 객실 안에서는 문 열어 탈출 가능. 이동 중 설정 시 도착 층까지 안전 이동.
모듈: src/explore/ElevatorSystem.js, ElevatorState.js
검토 URL: /?elevatorPreview=1 (2층 엘리베이터 앞), 기본 / 는 교실에서 시작.
이 변경은 아직 커밋/푸시하지 않음.
