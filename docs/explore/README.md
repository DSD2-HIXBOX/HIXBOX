# SCHOOL WALK · 사용자 GLB 자유 탐색

기본 페이지 `/`는 사용자가 제공한 `학교 파일.glb.zip`의 모델로 만든 탐색 환경입니다. 재난·타이머·미션·NPC를 실행하지 않습니다. 기존 재난 체험 코드와 자산은 그대로 두었으며 `/legacy.html`에서 실행할 수 있습니다.

## 실행

```sh
npm run dev
```

PC: http://127.0.0.1:5173/ → **PC 탐색 시작**. WASD 이동, 마우스 시점, E 문 열기/닫기, Shift 빠르게 이동, Esc 메뉴, R 시작 위치. 마우스 잠금을 지원하지 않는 내장 브라우저에서는 드래그 시점을 제공합니다. 눈높이는 바닥 위 1.6m입니다.

시작점은 2층 복도 `(40.4, 5.7496, -9.486)`이며, 실제 바닥 지지와 몸통 충돌을 검사해 초기화합니다. 화면 앞의 교실 문을 E로 열고 들어갈 수 있습니다. 열린 문을 다시 바라보고 E를 누르면 닫습니다. 문짝이 옆으로 이동해 조준점에서 벗어나도 열린 출입구에 대한 E 조작은 유지합니다.

## Meta Quest

- WebXR `immersive-vr`, `local-floor` 추적을 사용합니다. 헤드셋의 실제 높이와 시선을 반영합니다.
- 왼쪽 스틱: 머리 시선 기준 이동. 오른쪽 스틱: 30도 스냅 회전. 컨트롤러로 문짝을 가리키고 트리거: 열기/닫기. 원래 입력 모듈의 실제 숙이기 및 왼쪽 X 가상 숙이기도 유지합니다.
- 컨트롤러 레이는 조작 가능한 문 위에서 연두색으로 바뀌고, 헤드셋 안에 트리거 안내가 표시됩니다.
- 실제 고개/몸의 수평 이동도 같은 충돌 몸체로 검사해 룸스케일 이동으로 벽을 통과하지 않게 합니다.
- Quest에서는 **기기가 신뢰하는 HTTPS 주소**로 접근해야 합니다. 로컬 개발 서버는 기본적으로 이 PC의 loopback에서만 열립니다. 네트워크 테스트를 하려면 같은 Wi-Fi의 Mac LAN 주소와 해당 주소에 맞는 신뢰된 TLS 인증서로 실행하세요.

```sh
TLS_CERT=/absolute/path/cert.pem TLS_KEY=/absolute/path/key.pem npm run dev:https -- --host <Mac의-LAN-IP>
```

인증서가 없는 경우의 자동 자체서명 인증서는 Quest의 신뢰 설정에 따라 WebXR을 사용할 수 없습니다. HTTPS 호스팅에 `dist/`를 올리는 방법도 가능합니다. 파일을 `file://`로 직접 여는 방식은 지원하지 않습니다. 이 작업에서는 실제 Quest 기기로 추적·입력·프레임레이트를 검증하지 않았습니다.

## 원본 보존과 렌더링

- ZIP에서 추출한 원본: `public/models/explore/school.glb` (341,351,060 bytes). 원본은 수정하지 않습니다.
- 실행용 `render.glb`: 모든 5,186,945개 삼각형과 UV, 358개 재질, 82개 내장 이미지를 유지하면서 정적 메시를 공간/재질별로 묶었습니다. 재질 JSON과 이미지 바이트의 동일성을 테스트합니다. 원본의 오브젝트 변환을 정점 좌표에 적용하고 해당 묶음을 지역 좌표로 저장합니다. 메시 단순화, 텍스처 축소·대체를 하지 않습니다.
- 22,721개 메시를 3,782개 렌더 묶음으로 구성합니다. 투명 유리 등은 별도로 유지하고, 작은 식물 잎은 가까운 묶음으로 처리합니다. 보이지 않는 알파 0 메시와 멀리 있는 묶음은 런타임에 그리기를 생략하며 모델 데이터는 보존합니다.
- Quest에서는 DPR 1, XR framebuffer 0.8, 실시간 그림자 없이 실행합니다. 이 설정은 화면 렌더링 설정이며 모델 재질·텍스처를 바꾸지 않습니다.
- 원본이 큰 모델이므로 첫 로딩 시간과 메모리 사용량이 큽니다. 메시나 텍스처를 줄이는 최적화는 이번 요구사항에 따라 적용하지 않았습니다.

## 문 구조

`doors.json`에는 24개 출입구, 48개 기존 문짝과 손잡이의 원본 노드 번호가 기록되어 있습니다. 원본 벽/문틀/문 위 창은 고정한 채 기존 문짝만 실행 중 그룹에 재부모화합니다. 문짝을 복제하거나 문 개구부를 절개하지 않습니다.

별도 경첩 메시는 없습니다. 독립된 문짝의 바깥쪽 수직 모서리에 실행 중 회전축을 설정해 양쪽 문짝을 약 90도로 회전시킵니다. `HingedDoors.js`는 지수 보간 애니메이션을 적용하고 회전 중에도 실제 문짝 위치의 OBB 충돌을 유지합니다. 회전 구간을 2도 이하로 나누어 몸체와의 충돌을 검사하며, 문 앞에 사람이 있으면 정지했다가 비키면 재개합니다. 문이 열렸다는 이유로 모든 충돌을 꺼서 열린 문짝 자체를 통과하게 하지 않습니다.

별도 문짝으로 확인된 이 24개 출입구만 상호작용합니다. 이름만으로 사물함 문이나 다른 고정 면을 문으로 만들지 않습니다. 다른 층/공간의 벽과 합쳐진 면을 임의로 분리하거나 새 문으로 대체하지 않았습니다.

## 충돌

`collision.bin`은 모델에서 추출한 정적 삼각형 좌표이며 보이지 않는 대체 건물을 그리지 않습니다. 가변 문짝은 정적 충돌에서 제외하고 별도 동적 충돌로 처리합니다. `CompactCollider`는 typed array와 XZ 공간 인덱스로 벽·기둥·가구를 검사하고, 실제 위쪽 바닥/계단 삼각형을 보행 지지면으로 사용합니다. 다음 위치에 지지 바닥이 없으면 이동을 거부해 낙하를 막습니다. PC와 VR은 같은 충돌과 문 상태를 공유합니다.
