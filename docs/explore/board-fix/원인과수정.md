# 2층 복도 게시판: 원인과 수정

확인 위치는 INFORMATION 제목과 조직도 두 장이 붙은 2층 복도 게시판입니다. 별도 실내 원본과 사용자가 업로드한 통합본의 동일한 원본 노드 번호를 대조했습니다.

- 통합본의 바탕 패널은 삼각형 1개만 있어 사각형의 절반이 비어 있었습니다. 실내 원본은 2개로 완전합니다.
- 테두리는 원본 48개 중 24개, INFORMATION 글자는 원본 1,016개 중 605개 삼각형만 남아 있었습니다. 게시판 뒤 벽이 빈 곳을 통해 보이면서 게시판과 벽이 충돌한 것처럼 보였습니다. 손상은 이번 압축 이전의 업로드된 school.glb에도 이미 있습니다. 어떤 이전 변환 도구가 면을 제거했는지는 파일만으로 단정하지 않습니다.
- 테두리 뒤쪽 X 최댓값 약 36.3191m와 벽 표면 약 36.3184m도 약 0.7mm 겹쳐 있었습니다. 경계에서 깊이 충돌을 일으킬 수 있는 배치입니다.

해당 게시판의 원본 바탕·테두리·제목·부착물 7개 부품을 복원했습니다. 원본 UV·재질·이미지를 사용하며 새 문구나 텍스처를 만들지 않았습니다. 주변에 남은 조직도 좌표로 원본 배치를 맞췄고, 정합 오차 최댓값은 약 2.7mm입니다. 부품 전체를 복도 쪽(-X)으로 25mm 이동해 벽과 15mm 이상 간격을 확보했습니다. depth test를 끄거나 벽을 제거하지 않았습니다. 렌더링과 충돌 자산 모두 같은 배치를 사용합니다.

패널의 가로 5개 지점에서 빈틈 없이 면이 검출되는지, 테두리·제목의 원본 삼각형 수가 복구됐는지, 벽과의 간격, 기존 재질·이미지, 미닫이 문, 계단 및 PC/VR 모의 입력을 포함해 자동 검사 79개를 통과했습니다. 수정 전후 같은 시점의 화면은 before.png / after.png입니다. Quest 실기기와 macOS 앱의 더블클릭 실행은 직접 검증하지 못했습니다.

사용자 원본과 이전 배포본은 보존하며, 복원은 배치 및 충돌 생성 단계에서만 적용됩니다. 실제 앱에는 생성 완료된 자산이 들어 있어 별도의 실내 원본 경로가 필요하지 않습니다.
