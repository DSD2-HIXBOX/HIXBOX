# 실제 한국 고등학교 교실 적용 기록

## 로딩과 원본 보존

기존 `public/models`에 교실 폴더가 없어, 제공된 Downloads의 `korean_highschool_classroom`을
`public/models/classroom`으로 복사했습니다. `scene.gltf`, `scene.bin`, 텍스처 22개와 라이선스를 보존했습니다.
런타임 GLTFLoader가 상대 URI를 따라 원본 텍스처를 로딩합니다. 원본 파일, UV, 색상, 투명도,
metalness/roughness, double-sided 설정을 수정하지 않았습니다. 표시 결과에는 조명과 톤 매핑이 적용됩니다.
기존 임시 교실의 렌더링·가구·충돌·조명을 제외하고 실제 교실을 넣었습니다.
복도·계단·출입구·운동장과 공통 PC/VR 충돌 시스템은 유지합니다.

## 좌표와 크기

glTF의 Sketchfab/FBX 루트 변환을 모두 누적하면 원본 바닥은 약 0.22093×0.30190 단위입니다.
루트의 작은 스케일 때문에 파일의 메타데이터 단위를 그대로 미터로 볼 수 없어,
책상 상판 높이를 기준으로 **28배**를 적용했습니다(실측 자료가 없는 추정 보정).

- 바닥: 약 **6.19×8.45m**, 천장 약 **2.93m**, 전체 모델 높이 약 3.12m.
- 학생 책상 상판 높이: 약 **0.74m**, 폭 약 0.82m, 깊이 약 0.51m.
- 교실 바닥: 월드 Y=3.2m, 복도 쪽 오른쪽 벽 X≈5m.
- 원본 루트 회전을 유지하면 +Y가 위이고 전면 칠판 방향은 -Z입니다.
- 시작 발 위치: (4.55, 3.2, 3.35). 눈높이 1.65m, 칠판 쪽을 향합니다.
- 실제 모델에 맞춘 충돌체를 새로 등록했으며 임시 교실 충돌체는 남기지 않았습니다.

`src/world/classroom.js`에서 배율·위치·시작점과 모델별 노드 연결을 관리합니다.

## 문 분석

`scene.gltf`에는 애니메이션이 없지만 **벽과 분리된 문 패널 4개**가 있습니다.
벽은 노드 756(`polySurface1_standardSurface8_0`), 출입구 패널은 다음과 같습니다.

| 출입구 | 움직이는 패널 | 고정 패널 | 실제 개방 폭 |
|---|---|---|---|
| 앞문 | 노드 760, `polySurface4_standardSurface8_0` | 노드 762, `polySurface5_standardSurface8_0` | 약 0.83m |
| 뒷문 | 노드 764, `polySurface6_standardSurface8_0` | 노드 766, `polySurface7_standardSurface8_0` | 약 0.84m |

벽 메시의 출입구 위치에는 실제 구멍이 있습니다(삼각형 레이 교차로 확인).
따라서 메시 절단이나 UV 편집 없이 한 패널을 다른 패널과 겹치도록 **미닫이 이동**할 수 있습니다.
각 패널의 원래 부모 좌표계로 월드 이동량을 변환해서 적용합니다. 회전문 힌지나 신규 모델링은 필요 없습니다.
닫힌 상태부터 시작하며 E / VR 트리거로 열고 닫습니다. 이동에 맞춰 충돌체도 갱신합니다.
닫힐 경로에 사용자가 있으면 닫기를 거부하고, 이동 중 진입하면 동작을 반전해 관통을 방지합니다.
원본 파일은 변경하지 않으며 런타임 위치만 바꿉니다.

이 노드 번호는 **현재 파일에만 해당**합니다. 새로 export한 모델은 노드 구조가 달라질 수 있으므로
이름/의미를 확인해 DOORS 목록과 충돌 설정을 다시 연결해야 합니다.

## 책상 아래 이동

학생 책상·의자의 부품별 **삼각형 충돌**을 사용합니다. 책상 전체를 바닥부터 꽉 찬 박스로 만들지 않습니다.
벽·기둥·사물함은 간단한 박스로 처리하고, 문이 있는 벽은 출입구를 제외한 구간으로 나눕니다.

이 모델은 의자가 책상 안쪽으로 들어가 있으므로 다음 순서로 진입합니다.

1. 책상 옆에 서서 **의자를 바라보고 E** 또는 VR 트리거를 누릅니다. 의자가 약 65cm 뒤로 빠집니다.
2. **C 또는 Ctrl**로 숙이기/낮은 기어가기 자세를 켭니다.
3. 책상 뒤쪽으로 돌아서 책상 아래로 이동합니다. 책상 앞의 낮은 가로대와 양옆 다리는 실제로 막힙니다.
4. 책상 밖으로 나온 뒤 C/Ctrl을 다시 누르면 일어납니다. 상판/선반 아래에서는 자동으로 낮은 상태를 유지합니다.

가상 자세의 눈높이는 0.40m, 충돌 높이는 0.46m, 몸 반경은 0.18m입니다.
몸 모양은 이동용 캡슐 근사이며 인체/옷의 모든 부분을 재현하는 물리 시뮬레이션은 아닙니다.
의자는 메시·재질을 바꾸지 않고 완전한 의자 그룹만 이동하며 충돌 형상도 함께 갱신합니다.

VR에서는 실제 헤드셋 높이를 충돌 높이에 반영합니다. **왼쪽 X 버튼**으로 같은 가상 숙이기 기능을
켜면 서 있거나 앉은 상태에서도 낮은 공간을 탐색할 수 있습니다. 실제 바닥 기준 추적을 유지하기 위해
camera/controllers를 별도 trackingOrigin 아래 두고 이 그룹의 수직 오프셋만 조절합니다.
책상 아래에서 일어나도 가상 시점이 상판을 뚫지 않도록 상방 여유를 확인합니다.

## 검증 및 한계

`npm test`는 원본 의존 파일, 모델 크기/시작점, 벽 충돌, 닫힌 문 차단, 열린 문 통과와 운동장 왕복,
의자 빼기 → 책상 아래 진입 → 일어서기 제한, 문 닫힘 방지를 검증합니다.
헤드리스 geometry 테스트는 텍스처만 생략해 로딩하며 브라우저는 원본 텍스처를 로딩합니다.

모델은 약 80,856 삼각형, 375개 원본 mesh, 재질 37개, 텍스처 22개(다운로드 약 18MB)입니다.
모델 구조를 보존했으므로 Quest에서 draw call/투명 재질/메모리 비용은 실기 측정 후 최적화해야 합니다.
현재 지진/대피 정답 판정은 추가하지 않았습니다. 실제 Quest는 연결되지 않아 입력과 프레임률의 기기 검증은 남아 있습니다.

## 재현 가능한 분석

```sh
node scripts/inspect-classroom.mjs --json > docs/classroom-inspection.json
```

전체 노드 경로, 바운딩 박스, 메시 정보는 `classroom-inspection.json`에 있습니다.
GLTFLoader와 Box3 동작은 [Three.js GLTFLoader 문서](https://threejs.org/docs/pages/GLTFLoader),
[Box3 문서](https://threejs.org/docs/pages/Box3.html)를 참고했습니다.
