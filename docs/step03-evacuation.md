# STEP 03 · 지진 종료 후 교실 탈출

STEP 02의 올바른 보호 자세 유지가 끝나고 약 3초의 감쇠가 완료되면 자동으로 시작합니다. 기존 가구/사물함의 흔들림과 지진 소음은 멈추며 같은 교실에서 다음 행동을 이어갑니다. 학교 모델 파일과 기존 문·벽·바닥 충돌을 변경하지 않습니다.

## 안내 방송

> 흔들림이 멈췄습니다. 주변의 위험을 확인하고 안전한 경로로 대피하세요.

macOS의 한국어 Yuna 음성으로 생성한 약 5.4초의 실제 WAV 파일을 `public/audio/step3-announcement.wav`에 포함합니다. 22.05kHz 모노 16bit PCM, 약 236KB이며 외부 음성 서비스가 필요하지 않습니다. STEP 01의 시작 클릭으로 활성화된 Web Audio를 공유하여 재생합니다. 메뉴/비활성 탭/XR 일시정지에서는 방송 위치를 기억해 멈추고, 재개하면 이어서 재생합니다. 방송 문구는 PC와 VR 패널에도 표시합니다. 음성 로딩/디코딩 실패 시 지원 환경에서는 브라우저 한국어 음성 합성을 대체 수단으로 사용합니다.

## 가방과 조작

별도 경량 배낭 오브젝트를 사용합니다. 완료한 책상 옆의 원본 보행면과 충돌을 검사해 가방을 놓으며, 적합한 위치가 없으면 교실의 안전한 시작 위치를 사용합니다. 가방은 한 번 생성해 초기화 때 재사용합니다.

- **PC:** 책상 아래에서 나와 가까운 가방을 바라본 뒤 **E**로 집습니다. **F**로 머리 위에 올리고, 다시 **F**로 내립니다. 머리 위로 올라가는 애니메이션이 충분히 완료되어야 ‘가방으로 머리 보호 중’ 상태가 됩니다.
- **VR:** 책상 아래에서 나온 뒤 컨트롤러 손을 가방에서 .28m 이내로 가져가 **트리거**로 집습니다. 컨트롤러 위치와 회전을 그대로 따라갑니다. 실제로 머리 위에 올리고 머리의 수평 범위에 가방을 두면 보호가 활성화됩니다. 아래로 내리면 해제됩니다. 같은 손의 트리거를 다시 누르면 원래 안전한 위치에 내려놓습니다. 문은 빈손 컨트롤러로 조작할 수 있습니다.
- 몸을 낮춰야 손이 가방에 닿는 경우 기존 **Ctrl/C 또는 Quest X** 가상 웅크리기를 계속 사용할 수 있습니다.
- 가방은 손에 든 동안 보이는 소품이며 추가적인 무거운 물리 연산을 하지 않습니다. 머리 위 가방 때문에 카메라를 흔들거나 강제로 움직이지 않습니다.

### 안전한 집기 조건

가방이 바닥에 있고, 사용자의 머리가 실제 책상 아래 영역 밖에 있으며, 같은 층에서 수평 거리 .95m / 전체 거리 1.85m 이내일 때만 집습니다. PC는 시점 중앙의 실제 가방 메시를 E로 선택해야 합니다. VR은 손도 가방에서 .28m 이내여야 합니다. 머리와 가방, 손과 가방 사이의 벽/책상 등 차폐물을 레이캐스트로 확인해 벽이나 상판 너머로 집을 수 없게 합니다.

VR 보호 판정은 가방의 실제 월드 경계가 눈보다 최소 4cm 위에 있고 너무 높지 않으며, 가방 중심이 머리에서 수평 .35m 이내에 있는지 검사합니다. 손 추적을 잃으면 보호를 취소하고 가방을 원래 위치로 되돌립니다.

## F 키 역할 분리

`PCInput.onProtection`이 현재 단계의 입력을 우선 처리합니다.

- STEP 02 및 그 이전: 기존 **양팔 머리 보호 토글**.
- STEP 03: **가방 보호 토글**만 작동. 아직 가방을 집지 않았다면 집기 안내를 표시하고 양팔 상태를 바꾸지 않습니다.

복도 진입 후에는 F 입력을 소비하되 가방과 양팔 상태를 바꾸지 않고, 다음 단계에 보호 상태를 전달합니다.

STEP 03 시작 시 양팔 보호와 책상 다리 잡기는 해제하고 스마트폰은 내려둡니다. STEP 02의 판정은 완료 상태로 유지되며 더 이상 사물함/출입구 오답을 적용하지 않습니다. 전체 재시작 R은 모든 단계와 가방/방송을 초기화합니다.

## 문과 STEP 04 연결

기존 E/컨트롤러 트리거로 원본 문을 열고 실제 충돌을 통과해 복도로 이동합니다. 문에 가까이 가거나 열기만 해서는 전환하지 않습니다. 열린 원본 두 출입구 중 하나의 범위에서 몸이 교실 벽 바깥으로 약 .24m 통과한 순간만 검사합니다. 문이 열리는 애니메이션 도중에도 실제 통과 가능한 틈을 지나면 인식합니다.

별도 장면 로딩·화면 전환·텔레포트 없이 상단에 **STEP 04 · 복도 진입**을 표시하고 다음 상태를 기록합니다.

```js
{
  version: 1,
  completedStep: 3,
  currentStep: 4,
  status: 'entered-corridor',
  doorId: 0, // 또는 1
  bagCollected: true,
  bagProtected: true // 실제 진입 순간의 상태
}
```

`world.trainingState`, `sessionStorage['earthquake-vr-step3']`, `step4start` 브라우저 이벤트의 detail로 전달합니다. 이번 단계에는 가방 미보호 시의 오답/차단 규칙이 요청되지 않았으므로 복도 진입 자체는 허용하고, 진입 당시 가방 보유·보호 여부를 함께 저장합니다. STEP 04의 추가 대피 과제는 구현하지 않으며 기존 복도와 이동은 계속 사용할 수 있습니다.

## 검증

`tests/evacuation.test.js`에서 F 단계 분리와 반복 키 무시, 실제 음성 샘플, 가방 한 번 생성·재사용, 상판/벽 너머 집기 차단, PC 올리기/내리기, VR 추적·높이·추적 상실, 원본 문을 통한 연속 이동과 STEP 04 상태 저장을 검사합니다. 기존 STEP 01/02, F 양팔 보호, 전체 학교 이동/문/충돌 검사도 유지합니다.

`/tests/fixtures/step3.html`은 개발용 검증 화면입니다. QA 버튼은 제품 페이지와 배포본에 포함되지 않습니다. 실제 Quest의 손 자세·음량·접근성·프레임레이트는 헤드셋에서 최종 확인이 필요합니다.
