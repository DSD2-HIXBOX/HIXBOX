# STEP 02 · 교실 내 안전 행동

STEP 01의 재난문자 확인 후 지진이 시작되면 같은 장면에서 자동으로 이어집니다. 기존 학교 glTF 파일을 바꾸지 않으며, 복도/계단/출입구와 자유 이동도 보존합니다. 이번 스토리는 교실 내 행동 판정과 지진 종료까지만 구현합니다.

## 조작

- PC: WASD 이동, **Ctrl 또는 C**로 웅크리기 전환. 책상 아래에서 **E**로 책상 다리 잡기/놓기, **F 한 번**으로 양팔 머리 보호 켜기, **F 다시 한 번**으로 해제. 보호 중에는 양팔 애니메이션과 ‘머리 보호 중’ 표시가 나타납니다. PC에서는 다리 잡기 없이 웅크린 양팔 보호 자세로도 성공할 수 있습니다.
- VR: 실제 몸을 낮추거나 왼쪽 컨트롤러 **X**로 가상 웅크리기. 책상 아래에서 손을 실제 다리 가까이 가져가 **트리거**로 잡기/놓기. 잡은 손은 다리 가까이에 유지하고, **반대 손을 머리 가까이** 가져가 보호합니다.
- 문은 기존 E/트리거로 조작합니다. 사물함 가까이 서서 머무르거나 E/가까운 손의 트리거로 기대는 상호작용을 할 수 있습니다.
- 잘못된 행동/시간 초과에서는 **다시 선택하기**를 누릅니다. VR은 패널의 같은 버튼을 컨트롤러 레이로 가리키고 트리거를 누릅니다.
- **R / 시작 위치로**는 STEP 01부터 전체 재시작입니다. 실패 후의 **다시 선택하기**는 STEP 02만 재시작합니다.

초기 안내에는 정답과 오답을 표시하지 않습니다. 책상 아래에 접근했을 때만 필요한 자세/상호작용 조작을 안내합니다. 위 조작 설명은 개발·체험 안내이며 화면에 선택지 버튼으로 제시되지 않습니다.

## 판정

### 책상 아래

학교 원본의 학생용 목재 메시에서 가장 큰 수평 상판을 추출합니다. 같은 메시의 낮은 의자 좌판과 높은 등받이를 구분하고, 원본 고무 받침에서 책상 바깥쪽 네 다리 위치를 찾습니다. 상판 아래에 웅크린 몸이 들어갈 수 있는지 충돌 검사한 **36개 책상**만 등록합니다.

성공에는 다음 네 조건을 **1.5초 연속** 유지해야 합니다.

1. 머리의 수평 위치가 실제 상판 윤곽 안쪽에 있음.
2. 몸 높이 .6m 미만이며 머리 위 여유 6.5cm가 상판 아래에 있음.
3. VR은 해당 책상 다리를 잡고 있음. PC는 양팔 머리 보호로 이 조건을 대신할 수 있음.
4. PC의 F 토글 상태 / VR의 반대 손이 머리에서 .28m 이내이며 눈높이보다 8cm 이상 낮지 않음.

책상 아래 영역에 들어가거나 웅크리기만 해서는 성공하지 않습니다. VR 다리 잡기 시작 거리는 .24m이며, 잡은 뒤 .32m 이상 멀어지거나 추적을 잃으면 놓습니다. PC는 낮은 시점에서 닿는 가까운 다리에만 잡기 동작을 허용합니다.

기존 사각 충돌 근사치가 실제로 빈 좁은 진입 경로까지 막던 부분은 웅크린 몸의 반경 .15m와 발밑 .12m 여유로 보완했습니다. 서 있는 몸의 반경은 .18m이며 상판·의자·벽의 충돌을 유지합니다. 모델을 자르거나 의자를 삭제하지 않았습니다. 옆 통로에서 책상 앞쪽으로 돌아 낮게 들어가는 실제 경로를 테스트합니다.

성공 직후 차분한 초록색 안내를 잠깐 표시합니다. 이후 약 **6초 대기 + 3초 감쇠** 동안 같은 보호 자세를 유지합니다. 지진이 끝나기 전에 자세를 .65초 이상 잃으면 성공 대기를 취소하고 남은 선택 시간으로 돌아갑니다. 완전한 안전 자세를 제한 시간 안에 취한 경우 안정화 검사 중에 시간이 0이 되더라도 바로 실패하지 않습니다.

### 출입 시도

문을 가까이 바라보거나 여는 것만으로 실패하지 않습니다. 원본 두 출입구의 범위에서 문이 충분히 열린 상태로, 몸이 실제 공통 벽 바깥 방향으로 문턱을 지나 움직일 때 판정합니다. 문이 닫혀 있으면 기존 충돌이 통과를 막습니다.

실패 시 문 바깥 .65m 쪽으로 작은 마감재 네 조각이 떨어지고 짧은 경고음이 납니다. 낙하물은 시각 연출이며 사용자와 충돌하지 않습니다.

### 사물함

뒤쪽 벽에 있는 실제 높은 사물함 범위로부터 .48m 이내에서 서서 거의 움직이지 않는 상태가 **2.5초** 유지되면 판정합니다. 지나가는 동안의 체류는 이어서 누적하지 않습니다. 가까이서 기대는 E/트리거 상호작용은 즉시 판정합니다.

사물함은 원본 밑면 중심을 축으로 시각적으로만 최대 약 5° 앞으로 기울입니다. 사용자 이동·카메라·충돌체를 강제로 움직이지 않습니다.

### 시간 초과

안전 자세를 취하지 못한 선택 시간이 약 **15초**를 넘으면 실패 안내와 재시도 버튼을 표시합니다. 메뉴, 비활성 탭, 일시정지된 XR 세션 시간은 포함하지 않습니다. 성공 자세 유지 중에는 실패 타이머를 적용하지 않습니다.

## 재시도와 완료 상태

재시도는 시작 시점의 안전한 교실 위치, 서기 자세, 닫힌 두 문, 사물함 회전, 낙하물, 15초 타이머, 잡기/판정 상태를 복원합니다. 시작 위치가 이미 책상 아래처럼 서기에 부적합하다면 기본 교실 위치를 사용합니다. STEP 01 알림을 다시 재생하지 않습니다. VR은 명시적인 재시도에서 수평 위치만 재정렬하며 실제 헤드셋의 높이와 시점을 강제로 흔들지 않습니다.

낙하물 메시 네 개와 재시도 UI는 한 번 생성해 재사용합니다. 중복 타이머나 반복 지진 오디오 루프를 만들지 않습니다. 가구는 원본 위치 중심의 작은 애니메이션을 유지하고, 사물함은 낮은 주기의 무거운 떨림을 적용합니다. 스마트폰은 STEP 02 동안 내려두어 손을 사용할 수 있게 합니다.

지진 종료 시 다음 상태만 준비합니다.

- `world.trainingState`: `{completedStep:2,nextStep:3,status:'ready',action:'desk-shelter',deskId,protectedSeconds,version:1}`
- `sessionStorage['earthquake-vr-step2']`: 같은 JSON. 저장이 제한된 환경에서도 메모리 상태는 유지합니다.
- 브라우저 이벤트 `step2complete`: `detail`에 같은 상태.

STEP 02 모듈은 완료 상태를 저장합니다. 현재 앱에서는 별도의 STEP 03 모듈이 이를 받아 안내 방송, 가방 보호, 교실 탈출을 시작합니다. 상세 내용은 [STEP 03 문서](step03-evacuation.md)를 참고하세요.

## 모듈과 검증

- `src/world/safetyGeometry.js`: 실제 상판·다리·사물함 좌표와 보행 여유 추출.
- `src/story/ShelterState.js`: 순수 상태·시간·성공/실패 판정.
- `ShelterStep.js`: PC/XR 위치·자세·손 입력, 재시도와 완료 상태 저장.
- `ShelterUI.js`: PC 상단 안내 및 VR의 작은 캔버스 패널/재시도 레이 버튼.
- `ShelterEffects.js`: 재사용 낙하물과 사물함 기울기.

`npm test`에서 기존 기능 보존 외에 실제 책상 36개, 네 다리, 시작점에서의 진입, 보호 동작 필수 조건, 열린 문 통과, 사물함 체류/통과 구분, 시간 초과, 기한 직전 안전 자세, 성공 후 감쇠, 재시도 복원과 오브젝트 수 보존을 확인합니다.

개발 전용 `/tests/fixtures/step2.html`은 같은 실제 학교와 모듈로 이동 경로·실패·성공 화면을 검사하는 QA 버튼을 제공합니다. 이 버튼들은 제품 화면과 빌드에 포함되지 않습니다. 실제 Quest의 컨트롤러 손 위치, 진동·음량, 작은 플레이 공간의 접근성은 기기 검증이 필요합니다.
